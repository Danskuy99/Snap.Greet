Informasi & Ketentuan Jasa Snap.Greet

Panduan lengkap pemesanan kartu ucapan digital HTML dan layanan AI Photo Generation.

Alur Pemesanan

  1. Pilih template ucapan HTML atau sampel gaya foto AI dari katalog.
  2. Klik tombol Pesan untuk terhubung langsung ke WhatsApp Admin.
  3. Kirimkan data (Nama, Ucapan, Foto, atau Lagu) sesuai format balasan dari WA.
  4. Lakukan pembayaran via QRIS / E-Wallet / Transfer Bank.
  5. Admin memproses dan memberikan link website aktif atau file foto HD hasil karya.

Garansi & Privasi

  • Gratis Revisi: Penyesuaian teks & penggantian foto hingga 2x revisi.
  • Privasi Terjamin: Foto pelanggan dijamin aman dan langsung dihapus dari server pengerjaan setelah transaksi selesai.
  • Masa Aktif Web Ucapan: Website ucapan HTML dapat diakses selamanya (Hosted permanen).
  • Informasi Penting: Photo Generate tidak akan 100% mirip dengan Photo asli yang dikirimkan oleh pelanggan
